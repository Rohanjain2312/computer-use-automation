# Requirements matrix

Every MUST-HAVE from `ASSIGNMENT_LLM_FRIENDLY_SPEC.md`, where it is implemented,
and what proves it. Evidence paths are produced by `./scripts/demo.sh`.

Status: **done** · **done (scoped)** — implemented with a documented, deliberate
limit · **design** — the assignment asks for a design, not an implementation.
